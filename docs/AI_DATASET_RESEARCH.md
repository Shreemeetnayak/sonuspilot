# AI Dataset Research

## Legitimate Datasets
*   **FMA (Free Music Archive):** High-quality audio, genre tags. License: CC-BY-SA/CC-BY. Suitable for audio understanding training.
*   **MTG-Jamendo:** High-quality tracks, genre/mood/instrument tags. License: CC-BY-NC-SA. Suitable for audio representation learning.
*   **MagnaTagATune:** Crowdsourced tags, indie music. Suitable for tag-based conditioning.

## Provenance and Usage
*   Public datasets must be used for non-commercial audio representation learning only.
*   **Human Preference Data:** Must be sourced strictly from SonusPilot user interactions, never fabricated or scraped.
*   All licensed data must be documented with attribution where required.
